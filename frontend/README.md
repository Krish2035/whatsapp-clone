# WhatsApp Web Vercel - Frontend Web Application

[![WhatsApp Web Vercel Demo](https://img.shields.io/badge/Live%20Demo-WhatsApp%20Web%20Vercel-00a884?style=for-the-badge&logo=vercel&logoColor=white)](https://whatsapp-clone-nu-lyart.vercel.app)

Frontend web application for **WhatsApp Web Vercel**, built with **Next.js 16**, **React 19**, **Socket.IO Client**, and **Agora RTC SDK**, hosted and deployed continuously on **Vercel**.

## 🌐 Live URL
👉 **[https://whatsapp-clone-nu-lyart.vercel.app](https://whatsapp-clone-nu-lyart.vercel.app)**

## 🚀 Key Features
- **Real-Time WhatsApp Experience**: Instant chat messaging, group conversations, unread badges, typing indicators.
- **Agora Audio & Video Calls**: Crystal-clear WebRTC voice and video calls.
- **Audio Voice Notes**: Native mic recording with real-time waveform playback.
- **WhatsApp Status Stories**: Upload images/videos with disappearing timer stories.
- **Meta AI Chatbot**: Conversational AI assistant integrated seamlessly.
- **SEO & Social Share Ready**: Complete OpenGraph, Twitter Cards, Schema.org JSON-LD, `sitemap.xml`, and `robots.txt` optimized for ranking #1 for `"whatsapp web vercel"`.

## 🛠️ Scripts
```bash
npm run dev     # Start Next.js local development server (http://localhost:3000)
npm run build   # Generate optimized production build for Vercel
npm run start   # Run production server locally
npm run lint    # Run code linter
```
